1 检查 Resend 域名验证状态 Resend

你已在腾讯云 DNSPod 添加了 4 条 DNS 记录（DKIM、SPF MX、SPF TXT、DMARC）。现在需要确认 Resend 是否已验证通过：

  1. 打开 https://resend.com/domains 并登录
  2. 找到 longwoo.studio 域名记录
  3. 查看状态列：
    • Verified（已验证） — DNS 记录已生效，可以继续下一步
    • Pending（等待中） — DNS 传播中，通常需要 5~30 分钟，请等待后刷新页面
    • Failed（失败） — DNS 记录可能有误，点击域名查看详情，对比记录值是否正确
  4. 如果状态仍为 Pending，可以点击域名进入详情页，查看每条记录的验证状态
提示：DNS 传播通常需要几分钟到半小时。如果超过 1 小时仍未验证，请检查 DNS 记录的值是否与 Resend 提供的完全一致。
2 更新 Supabase SMTP 发件邮箱 Supabase

域名验证通过后，需要将 Supabase 的 SMTP 发件邮箱从 onboarding@resend.dev 改为 noreply@longwoo.studio：

  1. 打开 Supabase Dashboard 并登录
  2. 选择你的项目（vwxdjdmvgbfbpivpvxdg）
  3. 左侧菜单点击 Authentication → Providers
  4. 找到 Email 并展开
  5. 滚动到 SMTP Settings 区域
  6. 如果之前已启用自定义 SMTP，直接修改以下字段：
Host: smtp.resend.com Port: 465 Username: resend Password: [你的 Resend API Key] Sender email: noreply@longwoo.studio Sender name: LongWoo 龙坞
  1. 将 Sender email 从 onboarding@resend.dev 改为 noreply@longwoo.studio
  2. 将 Sender name 设为 LongWoo 龙坞
  3. 点击 Save 保存
重要：如果 Resend 域名状态还是 Pending，请不要修改发件邮箱。onboarding@resend.dev 只能发送到已验证的邮箱，而 noreply@longwoo.studio 在域名验证通过后可以向任意邮箱发送。
3 替换 Supabase 邮件模板（两个都要替换！）Supabase
关键：Supabase 有多个邮件模板。Confirm signup（新用户注册时触发）和 Magic Link（已有用户登录时触发）两个模板都必须替换，否则新用户会收到默认的英文确认链接邮件，而不是验证码。

3.1 替换 Confirm signup 模板（新用户首次登录时使用）：

  1. 在 Supabase Dashboard 左侧菜单点击 Authentication → Email Templates
  2. 选择 Confirm signup 模板
  3. 将 Subject 修改为：【LongWoo 龙坞】您的登录验证码
  4. 将 Message body 中的内容全部清空
  5. 打开项目根目录下的 supabase-email-template.html 文件
  6. 复制文件中的全部 HTML 内容
  7. 粘贴到 Supabase 的 Message body 输入框中
  8. 点击 Save 保存

3.2 替换 Magic Link 模板（已有用户登录时使用）：

  1. 在同一个 Email Templates 页面，选择 Magic Link 模板
  2. 将 Subject 修改为：【LongWoo 龙坞】您的登录验证码
  3. 将 Message body 中的内容全部清空
  4. 将刚才复制的 supabase-email-template.html 内容同样粘贴到这里
  5. 点击 Save 保存
模板说明：模板中的 {{ .Token }} 是 Supabase 的模板变量，发送邮件时会自动替换为实际的 6 位验证码。两个模板使用相同的 HTML 内容即可，请勿修改此变量。
为什么收到的是确认链接？因为 Confirm signup 模板还没替换。当新邮箱首次使用 signInWithOtp 登录时，Supabase 会使用 Confirm signup 模板发送邮件。只有替换了该模板并使用 {{ .Token }} 变量，才会发送数字验证码而非链接。

你也可以先打开 supabase-email-preview.html 在浏览器中预览邮件效果（使用示例验证码 839214）。模板已改用纯文字 Logo，不依赖外部图片，不会被 QQ 邮箱等邮件客户端拦截。

4 配置环境变量 Vercel

订单回复通知邮件通过 Resend API 直接发送，需要配置 API Key：

4.1 获取 Resend API Key：

  1. 打开 https://resend.com/api-keys
  2. 点击 Create API Key
  3. Name 填入 longwoo-platform
  4. Permission 选择 Full Access 或 Sending Access
  5. 点击 Create，复制生成的 API Key（以 re_ 开头）

4.2 配置 Vercel 环境变量（线上环境）：

  1. 打开 Vercel Dashboard
  2. 选择 longwoo-platform 项目
  3. 进入 Settings → Environment Variables
  4. 添加以下两个变量：
Key: RESEND_API_KEY Value: re_你的API密钥 Key: RESEND_FROM_EMAIL Value: noreply@longwoo.studio
  1. 添加完成后，进入 Deployments → 点击最新部署旁的 ... → Redeploy

4.3 配置本地环境变量（本地开发）：

  1. 打开项目根目录的 .env.local 文件
  2. 在 RESEND_API_KEY= 后面填入你的 API Key
  3. 保存文件
RESEND_API_KEY=re_你的API密钥 RESEND_FROM_EMAIL=noreply@longwoo.studio
5 测试验证码邮件 测试

所有配置完成后，进行端到端测试：

  1. 访问 https://www.longwoo.studio/login
  2. 输入一个非测试邮箱（例如 QQ 邮箱、163 邮箱、Gmail 等）
  3. 点击 发送验证码
  4. 检查该邮箱是否收到邮件，确认：
    • 发件人显示为 LongWoo 龙坞 <noreply@longwoo.studio>
    • 邮件主题为 【LongWoo 龙坞】您的登录验证码
    • 邮件顶部显示 LongWoo Logo
    • 验证码显示在深色品牌色背景的方框中
    • 邮件配色为深墨绿色（#0D3B3B）
  5. 将验证码输入登录页面，确认可以成功登录
测试通过：如果以上所有检查点都符合预期，说明邮箱验证码服务已完全配置成功！所有用户都可以收到品牌化的验证码邮件。
? 常见问题排查

Q: 邮件没有收到？

  • 检查垃圾邮件/广告邮件文件夹
  • 确认 Resend 域名状态为 Verified
  • 在 Resend Dashboard → Logs 页面查看发送日志
  • 确认 Supabase SMTP Sender email 已改为 noreply@longwoo.studio

Q: 邮件收到但 Logo 不显示？

  • 确认 https://www.longwoo.studio/logo.png 可以正常访问
  • 部分邮件客户端会拦截外链图片，需要用户点击"显示图片"
  • Logo 文件已在项目 public/logo.png 中，部署后可访问

Q: 验证码仍然是确认链接而不是数字码？

  • 在 Supabase Dashboard → Authentication → Providers → Email
  • 确认 Enable Email Provider 已开启
  • 确认 Confirm Email 设置正确
  • SMTP 配置后，Supabase 会自动发送 OTP 数字验证码而非链接

Q: Resend 域名一直显示 Pending？

  • 登录 DNSPod（腾讯云 DNS 控制台）
  • 检查 4 条 DNS 记录是否已添加：DKIM TXT、SPF MX、SPF TXT、DMARC TXT
  • 对比记录值与 Resend 域名详情页中显示的值是否完全一致
  • DNS 传播最长可能需要 24 小时，但通常 30 分钟内完成
